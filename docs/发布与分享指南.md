把《八字 · 四柱排盘》放到公网，并把它发给朋友测试。第一节是线上地址，后面依次是部署步骤（换机器重来时用）、发布前自检、发给朋友的文案、注意事项。

## 一、线上地址

**https://523855059-sketch.github.io/bazi/**

这就是要发出去的链接。仓库 `bazi` 在账号 `523855059-sketch` 下，Pages 已开启，对外提供的是 `main` 分支根目录。

- `bazi` 是仓库名，改名链接就跟着变。
- 必须是 https——只有 https（或本机 localhost）才允许注册 Service Worker，离线缓存和「添加到主屏幕」都依赖它。
- 项目内所有引用都是相对路径（`manifest.webmanifest`、`style.css`、`lib/*.js`），`start_url` 与 `scope` 都是 `./`，所以放在 `/bazi/` 这样的子路径下可以直接运行，不需要改任何代码。

## 二、部署步骤（当前已配置好，换机器重来时按这里走）

### 步骤 1　建仓库

浏览器打开 <https://github.com/new>：

- **Repository name**：`bazi`
- **可见性**：Public（Pages 免费版要求公开仓库）
- **不要勾选** Add a README / Add .gitignore / Choose a license——仓库必须是空的，否则推送会冲突
- 点 **Create repository**

### 步骤 2　绑定远程并推送

在 `八字排盘` 目录执行，把本地仓库和远端接上：

```bash
git remote add origin https://github.com/523855059-sketch/bazi.git
git push -u origin main
```

第一次推送会要求 GitHub 登录（浏览器或凭据窗口），登录一次后凭据会记住。

这台机器上 `origin` 已配好、`main` 已跟踪 `origin/main`，日常更新只敲 `git push` 即可。

### 步骤 3　开启 Pages

仓库页面 → **Settings** → 左侧 **Pages**：

- **Source**：`Deploy from a branch`
- **Branch**：`main`，目录选 `/ (root)`
- 点 **Save**

当前已是这个配置，构建来源为 `main` 分支根目录，改动推送后自动重新构建。

等 1–3 分钟刷新，页面顶部出现：

```
Your site is live at https://523855059-sketch.github.io/bazi/
```

### 步骤 4　自己先走一遍

发出去之前，用自己的手机打开链接，确认四件事：

1. 页面正常显示，填生日能排出四柱、大运流年；
2. 「添加到主屏幕」能成功（iPhone 用 Safari，安卓用 Chrome）；
3. 断网后再打开，页面还能用（说明离线缓存已生效）；
4. 填入 DeepSeek Key 后点「生成解读」，能流式出字。

任何一项不通过就先别发，回来修。

## 四、注意事项

### 对朋友要交代的

| 事项 | 怎么说 |
|---|---|
| **解读要自备 Key** | Key 由朋友自己去 platform.deepseek.com 申请，费用他自己承担。不填 Key 排盘照常，只是没有解读，**回测功能也需要 Key**。 |
| **不是注册制** | 没有账号、没有服务器，页面就是一串静态文件，打开就能用。 |
| **隐私** | 排盘全部在本机浏览器完成；只有点「生成解读」时才把命盘发给 DeepSeek。Key 存在他自己浏览器的 localStorage 里，不上传到任何第三方。 |
| **微信里打开** | 能看，但微信内置浏览器不支持「添加到主屏幕」。想要桌面图标，让对方在微信里点右上角「⋯」→「在浏览器打开」（iPhone 选 Safari，安卓选 Chrome）。 |
| **别当预测** | 页面底部已写明：传统术数推演，不构成医疗、投资、法律、婚育建议，不承诺准确性。发的时候带一句「图一乐」，别让对方面子上过不去。 |

### 你自己要知道的

| 事项 | 说明 |
|---|---|
| **国内访问 github.io** | 有时慢或间歇性打不开。朋友反馈打不开，先让他换个网络（4G / 换 WiFi）再试，多半是网络问题不是页面问题。 |
| **打开是 404** | Pages 还在构建（等 1–3 分钟），或者仓库 Settings → Pages 里的分支/目录选错了。 |
| **iOS 图标不完美** | manifest 里只有 `icon.svg`，iOS 的「添加到主屏幕」不认 SVG，会用网页截图当图标。要正经图标需要补一张 180×180 的 PNG 并在 `index.html` 里加 `apple-touch-icon`。 |
| **改了代码怎么生效** | 推到 `main` 分支后 Pages 自动重建，约 1 分钟。`sw.js` 是 network-first（在线永远取最新），朋友刷新就是新版，不用清缓存。 |
| **这个仓库只放代码** | 学生档案、家长材料属于私密内容，不进这个仓库。 |
| **支持范围** | 生日限 1900-01-01 至 2100-12-31，超出界面会报错；出生时间分「精确 / 大概 / 不确定」三档，选「不确定」时时柱按午时假定并标注。 |
| **功能边界** | 不做合婚、择日、姓名、风水。朋友问起别给出超纲承诺。 |

## 五、以后改了代码怎么更新

```bash
git add -A
git commit -m "说明这次改了什么"
git push
```

推送完等 1 分钟左右，Pages 自动重建。朋友那边刷新即是最新版；装到桌面的图标打开时走同一个地址，同样是新版。

## 六、备选方案（GitHub 走不通时）

| 方案 | 链接形式 | 适用 |
|---|---|---|
| 局域网 | `http://192.168.1.7:8000` | 朋友和你在同一个 WiFi 下。目录里跑 `python -m http.server 8000` 即可，但电脑不能关，且不是 https，装不了桌面图标。 |
| 临时隧道 | `https://xxxx.trycloudflare.com` | 异地朋友马上测。先装 cloudflared（`winget install Cloudflare.cloudflared`），一条命令把本地 8000 端口映射成公网 https，关掉就失效。 |
| 国内对象存储 | 自定义域名或存储桶域名 | 阿里云 OSS / 腾讯云 COS 的静态网站托管，需要实名和备案域名；好处是国内访问快。 |
