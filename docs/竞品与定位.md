# 竞品与定位

记录这个项目为什么这么做、和市面上的做法差在哪。数据来自 2026-11 的一次公开信息调研，来源见文末。

## 一、市场格局

### 专业排盘工具：问真八字

安卓 72.7 万下载，是这个品类的标杆。功能面铺得很宽：

- 自研「五柱排盘」，在四柱之外加一个维度
- 排盘时间覆盖公元 1 年 – 2099 年
- 真太阳时 + 出生地
- 排盘含四柱、十神、藏干、纳音、星运、空亡、神煞、滴天髓、参考用神、袁天罡称骨、五行占比
- 智能古籍参考（原文 / 译文 / 对照）
- 名人八字库 345 位、学堂 150 余本古籍
- 八字合盘、研究笔记
- 会员：季度 98、年度 198、永久 698

它的定位是**研究工具**：给懂命理的人用，把该有的数据都摆出来，不做白话解释。

### 综合平台：测测

占星、塔罗为主，八字只是其中一个板块。用户评价是「每个字都有解析，但大都比较笼统」「不要相信测测给的格局」。

### 通用大模型：豆包 / Kimi / DeepSeek

直接给生日就能出一篇解读，门槛最低。问题在排盘：模型自己「算」八字，遇到节气交接、立春分年、真太阳时这类边界，算错也看不出来。

## 二、用户的真实用法

社交平台上流传的标准流程是这样的：

1. 用问真、测测这类专业软件排盘
2. 截图
3. 把截图喂给 Gemini / DeepSeek / 豆包
4. 让它解读

用户的原话：

> 「别用 AI 排盘，它是瞎编的，问真是准的。」
>
> 「一定要自己给八字，不要让它们排盘。」
>
> 「豆包和 ds 比较谄媚，发现你对哪部分不满意就会更改话术圆回来。Gemini 好很多，但是真话会说得很难听。」

还有一个细节值得记：用户自己发明了验证方法——

> 「选取你人生的几个关键节点，比如中考高考的年份，让它说说那几年学业考试状况……和实际情况对应一下，如果比较符合，再问后面的事。」

这说明两件事：**用户不信任 AI**，而且**他们已经在用「回测过去」来判断可不可信**。只是这件事现在靠人手动做。

## 三、行业公认的四个问题

1. **排盘会错**。模型自己排，边界情况错得静默。
2. **解读不可验证**。套话多、无法核对、每次结果不一样。
3. **谄媚**。察觉用户不满意就改口，把结论圆回去。
4. **贵或有墙**。问真核心功能在会员后面（年度 198、永久 698）；测测每一步都可能要付费。

## 四、一个第三方实测

2026 年 10 月有人在 GitHub Pages 上放了一份实测（24 个公开案例、46 件人生大事、12 款工具与配置，统一模型）：

- 第一名「雪眠八字」对上 4 / 46 件
- 对照组「全说好事」（完全不看生日，只说会找到工作、会恋爱、钱会增加）对上 19 / 46
- 结论：这轮测试里没有一款工具胜过「说好话」对照

**必须同时记住它的边界**：作者自己写明这是探索性回测、不是未来准确率，来源是口述整理和论坛自述、未经独立核实，样本也只覆盖有大事的年份。它不能证明「算命是假的」，只能说明**在这轮测试里，看不出这些工具能稳定胜过简单对照**。

## 五、本项目的定位

**不卖「准」，卖「可查、可复现、不编」。**

「准不准」谁也证明不了（上一节的实测就是证据）。但下面三件事可以做到，而且能验证：

| 通用模型的问题 | 本项目的做法 | 怎么验证 |
|---|---|---|
| 排盘会错 | 节气时刻用 VSOP87 级数现算，102 项断言钉住 | `npm run verify` |
| 每次结果不一样 | 同一输入永远同一张盘、同一套判断 | 重复排盘对比 |
| 无法核对 | 每条结论带依据；旺衰打分逐项可展开 | 点开「命局判断」卡片 |
| 谄媚、说好话 | 提示词明令不讨好、不软化、不推荐转运物品 | 看 `lib/deepseek.js` 的 SYSTEM_PROMPT |
| 不能证伪 | 回测：填过去的事，对不上就提示可能时辰错了 | 用回测卡片自己试 |

## 六、对应到功能

| 竞品的短板 | 这里的对应功能 |
|---|---|
| 排盘错在边界 | 立春分年、节气分月、23 点换日、真太阳时，逐项有断言 |
| 只给结论不给推导 | 旺衰打分明细、格局取法依据、神煞查表基准，全部可见 |
| 永远说「对上了」 | 回测 + 「多数对不上 → 可能时辰记错」的提示 |
| 术语看不懂 | 口语化解读 + 界面术语注解 + 术语翻译表 |
| 出生信息外传 | 排盘全在本地，只有点「生成解读」才发命盘给模型 |
| 付费墙 | 无。只要自己的 API Key，按量计费 |

## 七、还没做的

- 五柱排盘、古籍原文对照、名人八字库、合盘——这些是问真的护城河，做它们等于做一个更小的问真，没有意义。
- 大运流月流日到日级：目前只到流年。
- 流派切换：口径写死在 `lib/analysis.js`。
