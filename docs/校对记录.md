# 校对记录

记录排盘引擎的对照数据与验证结论，供以后改动时复检。

## 一、节气时刻对照

算法算出的北京时间，与公开历书对照（容差 2 分钟，实测偏差在 30 秒内）：

| 年份 | 节气 | 算法结果 | 历书 | 偏差 |
|---|---|---|---|---|
| 2024 | 立春 | 02-04 16:26:55 | 16:26 | +55 秒 |
| 2024 | 春分 | 03-20 11:06:23 | 11:06 | +23 秒 |
| 2024 | 夏至 | 06-21 04:50:57 | 04:50 | +57 秒 |
| 2024 | 冬至 | 12-21 17:20:14 | 17:20 | +14 秒 |
| 2025 | 立春 | 02-03 22:10:14 | 22:10 | +14 秒 |
| 1984 | 立春 | 02-04 23:18:45 | 23:19 | −15 秒 |

偏差主要来自 ΔT 近似公式与历书取整，对排盘无影响（月柱切换的最小判据是分钟）。

## 二、日柱锚点

采用公示：`日柱序号 = (儒略日数 + 49) mod 60`，0 = 甲子。

| 日期 | 日柱 | 依据 |
|---|---|---|
| 2024-01-01 | 甲子 | 公开万年历（癸卯年 甲子月 甲子日） |
| 2000-01-01 | 戊午 | 公开万年历 |
| 1984-02-04 | 戊辰 | 公开万年历 |

连续性检查：从 2023-11-01 起 800 天，日柱逐日 +1，跨闰年、跨年、跨月无断点。

## 四、公式自查

- **五虎遁**：10 年干 × 12 月支 = 120 组合，与口诀表逐项比对，无差异。
- **五鼠遁**：10 日干 × 12 时辰 = 120 组合，无差异。
- **纳音**：60 甲子按 30 组对照，抽样（甲子=海中金、壬戌=大海水）通过。
- **十神**：以日干为我，比劫／食伤／财／官杀／印五组按同异阴阳区分，抽样（甲见庚=七杀、甲见辛=正官、甲见丙=食神、甲见癸=正印）通过。
- **大运**：阳年男顺、阳年女逆、阴年男逆；首步接着月柱；逆排到负下标时纳音仍能取到（戊年子月为甲子月，逆排首步 idx = −1）。
- **虚岁**：流年虚岁以立春年为基，与年柱同口径。

## 五、判断层对照

旺衰打分、格局、用神都是可复算的，下列用例可逐项核对（`1984-02-05 12:00 男`，四柱 `甲子 丙寅 己巳 庚午`）：

| 项 | 计算过程 | 结论 |
|---|---|---|
| 旺衰 | 月令寅木克己土，失令（死）−3；寅中戊 +0.5、巳中戊 +1、午中己 +1；月干丙印 +0.8；年干甲官杀 −1.2、时干庚食伤 −0.8、年支子财 −1、月支寅官杀 −1.2 | **−3.9，中和偏弱** |
| 格局 | 月支寅藏甲（本气）、丙（中气）、戊（余气）；甲透年干；甲对己为正官 | **正官格**（置信度高） |
| 用神 | 身弱用印比：取火（印）生身、土（比劫）帮身；忌水（财）木（官杀）金（食伤） | **用火，喜土，忌水木金** |
| 神煞 | 己日：天乙贵人在子申 → 年支子；禄神在午 → 时支午；年支子（申子辰）驿马在寅 → 月支寅，将星在子 → 年支子；日支巳（巳酉丑）桃花在午 → 时支午；子属亥子丑，孤辰在寅 → 月支寅 | 天乙贵人、禄神、驿马、将星、桃花、孤辰 |
| 空亡 | 己巳为甲子旬第 6 位，空戌亥 | 四柱未落 |
| 地支 | 子午冲（年时）、寅巳害（月日） | 冲、害各一 |

建禄格样例：甲日生寅月（禄位），取建禄格，`verify` 中遍历 2024 年 2 月自动找样。

## 六、怎么复检

```
npm run verify      # 全部断言（当前 96 项）
npm run build:jieqi # 重新生成节气表并自检间隔
```

改了 `lib/astro.js` 的级数系数，必须先跑 `build:jieqi` 再跑 `verify`；只跑 `verify` 用的是旧表。
