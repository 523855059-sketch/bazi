# 八字 · 四柱排盘与解读

手机浏览器打开就能用：填公历生日，排四柱、藏干、十神、五行、大运流年；需要解读时接上 DeepSeek 生成。

## 怎么用

- **直接打开**：双击 `index.html`，浏览器即可使用（全部脚本以普通 `<script>` 加载，不依赖服务器）。排盘功能完全离线。
- **手机上看**：把这个目录放到任意静态托管（GitHub Pages、对象存储、家里电脑的静态服务都可以），手机浏览器打开后「添加到主屏幕」，就是一个图标 App。通过 http(s) 访问时 Service Worker 会缓存全部文件。
- **本机起服务**：在目录里跑 `python -m http.server 8000`，然后访问 `http://localhost:8000`。

## 它做什么

- **排四柱**：年、月、日、时四柱干支，附天干十神、地支藏干及其十神、纳音。
- **公历与农历两种输入**：农历支持 1900–2100 含闰月，选完自动换算出公历再排盘。
- **出生地与时柱可信度**：内置 70 多个主要城市的经度，选城市即可换算真太阳时；出生时间分精确 / 大概 / 不确定三档，不确定时时柱会打上「假定」标记。
- **五行统计**：天干与地支本气计数，以及含藏干的完整计数。
- **命局判断**：日主旺衰打分（逐项可查）、格局判定（月令透干取格）、用神与喜忌（扶抑法，附调候提示）。
- **神煞与关系**：天乙贵人、文昌、禄神、羊刃、桃花、驿马、华盖、将星、孤辰寡宿、空亡，以及四支之间的合、冲、刑、害、破。
- **大运**：按年干阴阳与性别定顺逆，按「三天折一年」算起运岁数，排出十步大运。
- **流年**：从今年起十年，标出当年。
- **回测**：填 2–3 件已经发生的事（换工作、结婚、生病等），程序算出那几年的流年与原局的作用，由模型判断「按命理该发生什么」，你自己对照像不像。多数对不上时，会提示可能是出生时辰记错了。
- **AI 解读**：把命盘连同旺衰、格局、用神、神煞一起交给 DeepSeek，按八节结构写成口语，术语只作括号里的注脚（风格样例见 `docs/解读样例_口语版.md`）。

## 它和别的八字 App 有什么不一样

市面上的通行做法是两道工序：用问真、测测这类专业软件排盘，再把截图喂给通用大模型解读。中间那一环全靠人，而且排错了看不出来。

这个项目把两步做在一起，区别在三件事：

1. **排盘是你自己的，不是模型猜的**。节气时刻用天文级数现算，102 项断言逐条钉住；通用模型自己排盘会错，只是错得不明显。
2. **判断有推导过程**。旺衰为什么是 −3.9、格局凭什么取正官、每条神煞以什么为基准查的，都能点开看。
3. **能证伪**。填几件过去的事做回测，对不上就提示「可能是时辰记错了」——而不是永远说「对上了」。

通用模型的三个毛病——每次结果不一样、说好话讨好你、无法验证——在这里分别对应三件事：同一输入永远同一张盘；提示词明令不许讨好、不许推荐转运物品；每条结论带依据、可以回测。

## 排盘口径

这些是排盘正确性的关键，写清楚：

| 项 | 口径 |
|---|---|
| 年柱 | 以**立春**为界，不以正月初一为界 |
| 月柱 | 以**节**为界（立春、惊蛰、清明……），不以中气或农历初一为界 |
| 日柱 | 按儒略日连续推算 |
| 时柱 | 由日干五鼠遁推出 |
| 子时 | **23:00 起算次日**（早子时换日），界面会标注 |
| 真太阳时 | 默认关闭（按北京时间）；开启后按出生地经度算时差，并计入均时差。**只影响日柱与时柱**，年月柱的分界仍按节气的绝对时刻 |
| 旺衰 | 月令（旺+3 / 相+2 / 休 0 / 囚−2 / 死−3）＋通根（本气+2 / 中气+1 / 余气+0.5）＋天干帮扶−克泄耗（地支只计克泄耗，地支里的印星不另加分）；≥5 偏强，≥2 中和偏强，>−2 中和，>−5 中和偏弱，≤−5 偏弱 |
| 格局 | 月令藏干依次查是否透干，取第一个透出者为格；都不透则权以本气论并标「存疑」；月支为日主禄位取建禄格、刃位取羊刃格 |
| 用神 | 扶抑法：身弱用印比，身强用官财；中和按格局取；另附调候提示（冬生看火、夏生看水），只作补充不覆盖主结论 |
| 神煞 | 取通行表。神煞吉凶各家相反，程序**只报落位事实**，不下吉凶结论 |

节气时刻不是查表抄来的，而是用 VSOP87 地球黄经级数现算的：`lib/astro.js` 把太阳视黄经逼近到 `1e-7` 度，求解器对应时间误差远小于 1 秒。

## 它不做什么

- 不作医疗、投资、法律、婚育的具体决定建议。
- 不承诺准确性。解读属传统术数推演，不是科学结论。
- **不下神煞吉凶**：天乙贵人、桃花、羊刃这类神煞，各家吉凶判断相反，程序只报“命中有没有”，吉凶由解读层结合格局用神讲，并标注流派差异。
- 不做合婚、择日、姓名、风水。

## 关于解读与 API Key

- 排盘全部在本机完成。**只有点击「生成解读」时**，程序才会把命盘信息发送到 DeepSeek。
- Key 由你自己申请（platform.deepseek.com），只存在这台设备的浏览器 localStorage 里，不上传到任何第三方。
- 没填 Key 时排盘照常可用，只是没有解读。
- 实测（2026-11）`api.deepseek.com` 允许浏览器直连（预检回显 Origin），所以不需要自建代理。若将来策略变化，`lib/deepseek.js` 的 `ENDPOINT` 改成自建代理地址即可。

## 已知边界

- 支持范围 **1900-01-01 至 2100-12-31**，超出会明确报错。内部节气表前后各多算一年，保证边界日期算得出来。
- 输入的出生时间精确到分钟即可；公开排盘的秒级差异来自出生时刻本身的精度，不是算法。
- 农历输入支持 1900–2100 含闰月；农历年末可能换算到次年 1 月，超出 2100 年会明确报错。
- 出生地内置 70 多个主要城市（省会 + 主要地级市）；没有收录的城市可以手动填东经经度（73–135°）。
- 大运只排十步，流年只排十年，超出部分留到二期。
- 流派口径写死在代码里（子平格局派 + 扶抑取用），没有切换开关；换流派要改 `lib/analysis.js`。
- 出生时间分三档：精确 / 大概 / 不确定。选「不确定」时时柱按午时假定并打上标记，解读不会基于时柱下结论；程序不会静默替你造一个时辰。
